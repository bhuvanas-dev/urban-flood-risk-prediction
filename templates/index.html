About Project

Research project information.

Spatiotemporal Machine Learning for Early Prediction of Urban Flood Risk Using Rainfall, Terrain and Drainage Data

This project applies machine learning techniques to analyze structured urban environmental data and identify flood-related descriptive patterns.


Algorithm: XGBoost Classification

Feature Extraction: TF-IDF

Numerical Features: 7

Text Features: 7 input columns

Training Records: 2,400

Testing Records: 500

Frontend: HTML, CSS, JavaScript

Backend: Python Flask
